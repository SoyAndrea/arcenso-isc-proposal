# ARcenso: Expanding and Strengthening an R Package for Argentina's Census Data

This repository contains the proposal submitted to the R Consortium Infrastructure Steering Committee (ISC) to support the continued development of [ARcenso](https://github.com/SoyAndrea/arcenso), an open-source R package for reproducible access to Argentina's official census statistics.

The proposal focuses on strengthening ARcenso's technical infrastructure, preparing the package for its first release on CRAN and distribution through R-universe, and expanding its coverage of historical census data.
